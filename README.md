Embarque em uma aventura desafiadora neste roguelike 2D com temática de fantasia, onde o mundo é renderizado em belos gráficos pixelados. Enfrente hordas de inimigos em masmorras geradas proceduralmente, utilizando uma variedade de armas de fogo para se defender. Cada batalha é uma oportunidade de crescer; ao subir de nível, desbloqueie poderosos upgrades que transformarão suas habilidades e estratégia. Prepare-se para explorar, lutar e sobreviver em um universo onde cada decisão pode ser a diferença entre a vitória e a derrota.
